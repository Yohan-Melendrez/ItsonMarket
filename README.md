Para correr esta app primero instala las dependencias: npm install

En el archivo db.js se utilizo una BD de MongoDB Atlas.Se puede usar la URI para abrirla en MongoDB Compass.

Si no se puede hacer la conexion mediante la URI en la carpeta del proyecto esta un .JSON con la coleccion que se uso para el proyecto no mas seria ingresarla en la bd local.

Luego ya se puede correr el programa con: node main.js
